# Task Management System

A desktop-based Task Management System developed using Java Swing. It provides a simple and user-friendly interface to create, manage, update, and track tasks.

## Features

- **Add Tasks:** Create tasks with a title and description.
- **View Tasks:** Display all available tasks in a table.
- **Update Tasks:** Edit existing task details.
- **Delete Tasks:** Remove tasks when no longer needed.
- **Task Status:** Track tasks as Pending, In Progress, or Completed.
- **Input Validation:** Prevent tasks from being created without a title.
- **Dashboard:** View total tasks and status-wise task summaries.
- **Empty State Message:** Display a message when no tasks are available.

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/fatimazulfiqar529/Task-Management-System.git
```

**2. Navigate to the project folder**

```bash
cd Task-Management-System
```

**3. Compile the Java files**

```bash
javac -d . src/*.java
```

**4. Run the application**

```bash
java TaskManager
```
